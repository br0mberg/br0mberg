### Инженерный фокус и компетенции

* **Архитектура и System Design:** Уверенное владение классическими паттернами (GoF, SOLID). Проектирование микросервисной архитектуры, Event-Driven систем и надежных межсервисных интеграций (Transactional Outbox, gRPC, Kafka).
* **Performance & High-Load:** Профилирование JVM, оптимизация сложных SQL-запросов, работа с конкурентным доступом к данным, решение проблем производительности в legacy-коде.
* **Data & AI Integrations:** Построение высоконагруженных ETL-процессов (Apache NiFi) и проектирование RAG-архитектуры для интеграции LLM в enterprise-среду.
* **DevOps & Observability:** Контейнеризация (Docker, k8s), настройка CI/CD пайплайнов, внедрение практик наблюдаемости (Grafana, Loki) для быстрого траблшутинга инцидентов.

* **Языки:** Java (14, 17, 21), Groovy, Python, PL/SQL, C/C++.
* **Backend:** Spring Framework (Boot, Data, Security, Cloud, AI), Hibernate, Quarkus. Основательная база: Java Core, ООП, SOLID.
* **Архитектура и Контракты:** REST API, gRPC, Protobuf, SOAP, OpenAPI/Swagger.
