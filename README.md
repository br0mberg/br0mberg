# Андрей Бромбин

**ML-инженер · бэкенд для LLM и RAG · преподаватель**

Готовлю датасеты, обучаю и дообучаю модели, проверяю их на отдельных выборках и интегрирую в сервисы. Для RAG экспериментирую с поиском по документам и реранкингом, измеряю качество выдачи и задержку. Разрабатываю бэкенд на Java и Python.

## Проекты

- **RAGVIEW** — воспроизводимый стенд для сравнения векторного поиска, BM25, гибридного поиска с RRF и реранкинга BGE на Налоговом кодексе. [Код и результаты](https://github.com/br0mberg/ragview-rag-types)
- **Incident Retrieval Service** — RAG-прототип для системы поддержки на Java, Spring AI и Qdrant. [Репозиторий](https://github.com/br0mberg/SupportDesk-IncidentRetrievalService)
- **SupportDesk** — микросервисы для обработки инцидентов и межсервисного обмена через Kafka и gRPC. [Репозитории](https://github.com/br0mberg?tab=repositories&q=SupportDesk)

## Технологии

- **ML и NLP** — Python, PyTorch, Hugging Face Transformers, scikit-learn, LoRA/PEFT, ONNX Runtime.
- **LLM и поиск** — Spring AI, Qdrant, Apache Lucene (BM25), эмбеддинги, RRF и реранкинг.
- **Бэкенд и инфраструктура** — Java, Spring Boot, FastAPI, PostgreSQL, Kafka, gRPC, Docker и Kubernetes.
